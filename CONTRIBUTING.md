# Contributing to MiniLinux

Contributions are welcome.

For normal bugs and improvements, open an issue or pull request.

For vulnerabilities or other security-sensitive issues, follow the
process described in [SECURITY.md](SECURITY.md).

Changes affecting the following areas require security review:

- boot verification;
- image signing;
- TLS and certificate handling;
- SSH authentication;
- provisioning and recovery;
- secret or key handling.

All contributions should avoid committing private keys, credentials,
tokens, recovery keys, or other secrets.
